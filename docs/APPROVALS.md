# 승인·질문 지원표

브리지는 사용자가 실제 누른 응답을 전달합니다. 승인을 자동 허용으로 바꾸거나 범위를 확대하지 않습니다.

전체 요청 목록과 완료 기준은 [승인·질문 전체 지원 기준](POPUP-COVERAGE.md)에 기록합니다. 현재 지원표와 후속 구현 목표를 구분합니다.

| 요청 | 0.19.0 상태 |
|---|---|
| 터미널 명령 실행 승인 | 지원: 실제 제공된 허용·거부·취소, 세션 허용·제안 규칙 중 검증된 형식 |
| Computer Use의 앱 사용 승인 | 지원: 빈 입력 스키마의 앱 접근 요청, 제공된 이번 대화/항상 허용 범위 |
| 명령의 네트워크 정책 변경 제안·STDIN 승인 | 제시된 네트워크 대상/규칙과 개별 콜백에 묶어 전달 |
| 파일 변경 승인 | 허용·세션 허용·거부·취소. 실제 변경 내역까지 대조 |
| 인터넷·파일 시스템 추가 권한 요청 | 지원: 요청된 권한 그룹의 허용·거부, 이번 턴/세션 범위. 알 수 없는 환경·확장 응답은 거부 |
| 선택형/자유 입력 질문 | 여러 질문·부분 답변·빈 응답, 초기 설정의 질문형 도구 전달 |
| 일반 MCP 입력 폼·URL 계속 | 지원되는 스키마의 값과 선택을 전달. URL을 열었다고 자동 완료하지 않음 |
| 앱·웹사이트 접근 승인 | 빈 폼 또는 지원되는 폼의 원래 응답과 제공된 허용 기간 전달. GPU 공식 앱의 안전성 검사를 유지 |
| 원본 계획 실행 | 마지막 완료 턴의 원본 계획과 정확히 일치할 때 Plan → Default로 실행. 피드백은 일반 메시지로 전달 |
| 계획 편집본 실행·닫기 | GPU 공식 앱 필요 |
| 옵션 선택기·역할/작업 초기 설정 | 현재 공식 앱의 원격 응답 경로 없음. GPU 공식 앱 필요 |
| 브라우저 인증·커넥터 OAuth·플러그인 설치 제안 | GPU 계정/브라우저/설치 완료 경로 연결 미지원 |
| 파일 선택·일부 확장 입력 폼 | GPU 파일 선택, 정규식/$ref 등 지원하지 않는 스키마는 GPU 공식 앱 필요 |
| 진행 중 작업 중지·개입 | 미지원 |
| 대기 메시지 조회 | 지원. 대기 메시지 추가·수정·삭제·실행은 미지원 |

미지원 요청에는 연결 창 본문에 **Session Bridge 연결 안내**가 표시됩니다. 이 안내는 연결 창에만 붙이며 GPU 대화 기록과 원래 요청을 변경하지 않습니다. GPU의 공식 Codex에서 같은 작업을 열어 처리하세요. 옵션 선택기가 잘못 보낸 직접 응답은 GPU로 전달하지 않고 연결을 유지합니다.

지원 표는 코드와 격리된 전송 검사 기준입니다. 이번에 추가한 모든 유형의 실제 화면 왕복을 완료했다는 뜻은 아닙니다. 응답 전 원래 소유자·요청·턴·내용을 재확인하고, 응답 후 요청이 사라지는지도 관찰합니다. 결과가 불확실하면 자동 재전송하지 않습니다. 질문 답변·폼 값은 응답 기록에 원문으로 남기지 않습니다.

샌드박스 초기화 실패 때문에 반복 승인이 발생하는 경우, 이는 호스트의 실행 환경 문제일 수 있습니다. 브리지는 해당 경고를 숨기거나 샌드박스를 비활성화하지 않습니다. 호스트 오류를 별도로 해결해야 합니다.
