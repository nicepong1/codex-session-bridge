# 승인·질문 지원표

브리지는 사용자가 실제 누른 응답을 전달합니다. 승인을 자동 허용으로 바꾸거나 범위를 확대하지 않습니다.

| 요청 | 0.18.2 상태 |
|---|---|
| 터미널 명령 실행 승인 | 지원: 실제 제공된 허용·거부·취소, 세션 허용·제안 규칙 중 검증된 형식 |
| Computer Use의 앱 사용 승인 | 지원: 빈 입력 스키마의 앱 접근 요청, 제공된 이번 대화/항상 허용 범위 |
| 명령의 네트워크 정책 변경 제안 | 미지원 |
| 파일 변경 승인 | 미지원 |
| 추가 권한 요청 | 미지원 |
| 선택형/자유 입력 질문 | 원격 응답 전달 미지원 |
| 범용 MCP 폼, 플러그인·커넥터 승인, OAuth | 미지원 |
| 웹사이트 접근·브라우저 이력·확장 프로그램 승인 | 미지원 |
| 계획 실행, 초기 설정, 옵션 선택 요청 | 미지원 |
| 진행 중 작업 중지·개입 | 미지원 |

미지원 카드가 보이거나 버튼이 반응하지 않으면 호스트의 공식 Codex 앱에서 처리합니다. 카드가 없어졌다고 실제 처리가 완료된 것으로 간주하지 않습니다. 지원하는 승인도 원래 소유자·활성 요청·턴·요청 내용을 재확인하고 결과를 관찰합니다.

샌드박스 초기화 실패 때문에 반복 승인이 발생하는 경우, 이는 호스트의 실행 환경 문제일 수 있습니다. 브리지는 해당 경고를 숨기거나 샌드박스를 비활성화하지 않습니다. 호스트 오류를 별도로 해결해야 합니다.
