# 호환성

| 역할 | 검증된 버전 |
|---|---|
| 클라이언트 Windows x64 공식 Codex 앱 | 26.901.5280.0, 26.901.6511.0 |
| 호스트 Windows x64 공식 Codex 앱 | 26.901.5280.0, 26.901.6511.0 |
| 호스트 공식 CLI 캐시 | codex-cli 0.153.4 |
| 이 릴리스에 포함된 Node.js | 24.20.0 x64 |
| 양쪽 브리지 | 0.18.1 |

실제 기준은 루트의 `compatibility.json`입니다. 현재는 Windows Store 패키지 형태의 공식 앱을 식별합니다. 다른 배포 형태, 여러 버전의 앱을 동시에 실행한 상태, Windows ARM64, macOS, Linux는 검증하지 않았습니다.

호스트 CLI는 `%LOCALAPPDATA%\OpenAI\Codex\bin`의 캐시에서 지원 버전의 실행 파일을 찾습니다. 캐시 폴더 이름이나 사용자 이름을 고정하지 않습니다. 지원되는 CLI가 없으면 임의의 CLI로 대체하지 않습니다.

앱 업데이트로 호환성이 달라지면 `Diagnose.cmd`에 실제 감지 버전과 실패 단계가 나옵니다. 매니페스트의 버전 문자열만 수정해 차단을 해제하지 마세요. 새 버전의 IPC·입력·승인 경로를 검증한 릴리스가 필요합니다.

이 릴리스의 기능 범위는 공개 전에 누적된 기존 Windows 연결 검증을 바탕으로 합니다. 다른 모든 PC 조합에서 동작한다는 보증은 아니며 첫 공개 시험판입니다.

원격 Windows OpenSSH의 기본 명령 셸 구성을 기준으로 검사했습니다. `%` 기호가 포함된 호스트 설치 경로는 지원하지 않습니다. [실제 검증 범위](VALIDATION.md)를 참고하세요.
