# 릴리스 검증 기록

0.18.0 공개 시험판을 준비하며 다음을 확인했습니다.

- Windows 자동 검사 **167개 통과**: 연결 설정 분리, SSH 지문 일치/불일치, 잘못된 인수 거부, 호환성 차단, 캐시 탐색, 입력·승인 중복 방지, 본문 사전 읽기, 목록 정렬, 창 식별, 원격 실행 제한.
- 포함 런타임과 Windows 셸 사이에서 한글·이모지의 양방향 바이트 전달, 표준 입력 종료 후 프로세스 종료 확인.
- 임시 사용자 폴더에서 실제 설치, 같은 버전 재설치, 변조된 설치 파일의 재설치 거부, 제거 및 사용자 데이터 보존 확인.
- 두 Windows PC의 실제 SSH 연결에서 앱/CLI/IPC 진단 성공. 같은 26.901.6511.0 앱의 관련 프로그램 파일 해시와 연결·입력·승인 메서드 버전 일치 확인.
- 새 설정과 원격 설치 경로로 실제 작업 목록 10개 조회, 작업 ID 형식과 한글 제목 전달 확인. 해당 조회는 SSH 작업자 시작을 포함해 약 1.3초였으며 작업 클릭 화면의 지연 측정은 아닙니다.
- 배포 소스와 ZIP에서 개인 기록·계정·키·프로필을 제외하는 파일 명세 검사, 공식 Node.js ZIP 및 배포 파일 SHA256 검증.

기존 개인용 버전에서 확인했던 공식 화면의 작업 선택·입력·모델 변경·지원 승인 동작을 이어받았습니다. 첫 공개 패키지의 모든 UI 동작을 새로운 사용자 PC마다 재현했다는 뜻은 아닙니다. 다른 OS, 알 수 없는 Codex 빌드, 지원표에 없는 승인 종류는 검증 완료 범위에 포함하지 않습니다.
